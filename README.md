# Conformal Prediction for Distribution-to-Distribution Regression

This repository contains the source code for the paper  
**“Conformal Prediction for Distribution-to-Distribution Regression.”**

The codebase implements conformal prediction methods for distribution-to-distribution (D2D) regression, where both inputs and outputs are probability distributions represented via Fourier coefficients.

---

## Repository Structure

```text
.
├── models/        # D2D regression models
├── tasks/         # Experimental tasks and ablation studies
├── utils/         # Shared utilities (Fourier, sampling, data loading, etc.)
└── README.md
```
## Running Experiments

All experimental scripts are located in the `tasks/` directory.

👉 Detailed instructions for running experiments and reproducing results can be found in the README files inside the `tasks/` folder.
